# PGP-Encryption-and-Secure-Email-Communications

# Project Objective

This lab was a school assignment from January 2025 where I was tasked with making a video demonstrating how to create an email with encryption using any tool of my choosing and the implementation of end-to-end email security using PGP (Pretty Good Privacy) to ensure the confidentiality and integrity of sensitive communications.

[Video Link](https://www.youtube.com/watch?v=_V6M4D8y5co)

# Technical Environment

Operating System: Windows/Linux

Encryption Software: Kleopatra / GnuPG

Encryption Standard: OpenPGP (RSA-4096)

# Workflow Breakdown

Key Pair Creation: Generated a 4096-bit RSA key pair protected by a secure passphrase.

Public Key Distribution: Outlined the process of sharing public keys to enable secure inbound communications.

Encryption Lifecycle: Demonstrated the conversion of plaintext into PGP-armored ciphertext and the subsequent decryption back to the original message.
